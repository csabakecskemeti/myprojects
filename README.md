# My Projects

Git-based project tracker and knowledge base.

## Quick Start

```bash
# Scan local repos
./scripts/scan-repos.sh ~/Documents/workspace ~/code

# Analyze a specific repo
./scripts/analyze-repo.sh /path/to/repo
```
