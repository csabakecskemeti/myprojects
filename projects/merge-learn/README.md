# Merge Learn

Distributed learning with minimal network communication between GPUs.

## Problem

Standard distributed training requires heavy inter-GPU communication. This project explores approaches that minimize network transfer.

## Solution

Merge-based distributed learning — train locally, merge weights, minimize bandwidth.

- **Language:** Python
